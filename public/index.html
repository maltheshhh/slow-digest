Open by design

Why the model is open

Chats stay on your machineGroup chats hold other people's messages. A local model reads them without sending a word to a server you do not control.
Works with the wifi offThe server talks to Ollama on localhost. The rule-based digest keeps working even when no model is installed.
Swap the brainSet OLLAMA_MODEL or pick a model per request. Try a smaller one for speed or a larger one for nuance.
Costs nothing per runNo API key, no meter running while you sleep.
